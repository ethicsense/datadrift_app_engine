Silhouette Outliner — macOS 데모 실행 안내
작성일: 2026-06-08

이 패키지는 내부 데모용이며 Apple Developer 서명·공증(notarization)이
적용되어 있지 않습니다. 처음 실행 시 macOS 보안 경고가 나타나는 것은
정상입니다. 아래 순서대로 진행해 주세요.


■ 1. 압축 해제

  SilhouetteOutliner-macos.zip 을 원하는 폴더에 풉니다.
  같은 폴더에 다음이 있어야 합니다.

    - Silhouette Outliner.app
    - macOS-실행방법.txt  (이 파일)


■ 2. 보안 경고가 뜨는 경우 (권장: 터미널)

  macOS가 "'Silhouette Outliner.app'을(를) 열지 않음" 또는
  "악성 코드 여부를 확인할 수 없음" 안내를 표시할 수 있습니다.

  가장 간단한 해결:

    1) 터미널(Terminal.app)을 엽니다.
    2) 아래 명령을 실행합니다. (경로는 실제 위치에 맞게 수정)

       xattr -dr com.apple.quarantine "/경로/Silhouette Outliner.app"

       예) 다운로드 폴더에 풀었다면:

       xattr -dr com.apple.quarantine ~/Downloads/"Silhouette Outliner.app"

    3) Finder에서 Silhouette Outliner.app 을 더블클릭해 실행합니다.


■ 3. 시스템 설정에서 허용 (대안)

  터미널 사용이 어려울 때:

    1) Silhouette Outliner.app 실행을 한 번 시도합니다.
    2) 경고 창에서 [완료]를 누릅니다. ([휴지통으로 이동]은 누르지 마세요.)
    3) 시스템 설정 → 개인정보 보호 및 보안 을 엽니다.
    4) 아래쪽에 "'Silhouette Outliner.app'이(가) 차단되었습니다" 문구가
       보이면 [그래도 열기]를 클릭합니다.
    5) 다시 앱을 실행하고 확인 창에서 [열기]를 선택합니다.

  macOS 15(Sequoia) 이상에서는 우클릭 → 열기 만으로는 허용되지 않을 수
  있습니다. 위 두 방법 중 하나를 사용해 주세요.


■ 4. 앱 사용

  - 플랫폼: 무신사 선택 후 [분석 실행]
  - 분석 시 인터넷 연결 필요
  - 보고서 저장 위치:

    ~/Library/Application Support/SilhouetteOutliner/runs/


■ 5. Windows와의 차이

  Windows는 SmartScreen "신뢰할 수 없음" 경고 후 [추가 정보] → [실행]으로
  바로 열리는 경우가 많습니다. macOS는 위 2번 또는 3번 절차가 한 번
  필요합니다.


■ 문의

  실행·분석 오류가 계속되면 로그 화면 내용과 함께 전달해 주세요.
