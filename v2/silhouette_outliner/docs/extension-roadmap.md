# 확장 로드맵

작성일: 2026-05-13

## 1단계: 현재 MVP

- `sectionId=199` 중심 수집
- 요청 카테고리의 `categoryCode` 조합 수집
- 상품/브랜드/가격/할인 정규화
- 카테고리별 요약, 브랜드 점유율, 가격/할인 분포 리포트
- 네트워크 JSON 우선, DOM fallback

## 2단계: 기간/성별/연령 확장

- 기간: 일간, 주간, 월간 필터 파라미터 식별
- 성별: 전체, 남성, 여성
- 연령: 19-40 범위의 실제 `ageBand` 코드 매핑
- 보고서: 성별 × 연령 × 카테고리 히트맵, 타겟별 TOP 브랜드

## 3단계: 상위 랭킹 목록 확장

- 급상승, 부티크, used 등 `sectionId` 매핑 보강
- section별 중복 상품 및 브랜드 이동 분석
- `전체`에는 없지만 `급상승`에 있는 신규 후보 탐지

## 4단계: 판 데이터 조인

- 콘텐츠판: 콘텐츠 제목, 브랜드, 조회수, 댓글, 연결 상품
- 세일판: 할인율, 소진율, 행사명, 노출 위치
- 추천판/배너: 노출 위치, 링크, 브랜드
- 보고서: 판 노출 브랜드의 랭킹 진입률, 판 미노출 랭킹 상품 후보

## 5단계: 외부 채널 신호

- 유튜브: 브랜드명/상품명 기반 검색, 최근 영상, 조회수, 게시 시점
- 인스타: 해시태그/릴스/게시물 신호
- 뉴스: 브랜드명/상품명 언급량과 최근성
- 보고서 표현은 확정 원인이 아니라 `외부 요인 후보`로 제한

## 6단계: 운영화

- 카테고리/섹션 매핑 자동 discovery
- 실패 조합 재시도
- 수집 로그와 스냅샷 diff
- 과거 run 간 순위 변화 분석
- 정적 HTML 외 CSV/Parquet export
