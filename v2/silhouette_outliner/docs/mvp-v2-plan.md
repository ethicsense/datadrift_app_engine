## 분석 정의

### 1. Heat Score (실시간 화제성)

```
heat = (viewers_now or 0) + (buyers_now or 0) * 2
```

가중치 2배의 근거: "구매 중"은 결제 진입까지의 강한 의사결정 신호로 단순 시청보다 정보가 풍부하다. 가중치는 `analyze.py` 모듈 상단 상수 `HEAT_WEIGHT_BUYERS = 2`로 노출한다.

### 2. 순위 × 검증 신호 산점도 (회귀선 + 잔차)

플랫폼 평점은 사용하지 않는다(아래 사유 참조). 대신 플랫폼이 조작하기 가장 어려운 세 신호를 가중합한 **Validation Score**를 Y축으로 둔다.

```
validation = 0.5 * log10(review_count + 1)
           + 0.3 * log10(buyers_now + 1)
           + 0.2 * sales_label_score
```

- `review_count`: 누적 리뷰 수. 표본 전수에 존재, 평점과 달리 양 자체는 조작 비용이 크다.
- `buyers_now`: "N명이 구매 중" 실시간 카운터. 실제 결제 진입을 셈, 위조 거의 불가.
- `sales_label_score`: `image.labels[]`의 "판매 N만개" / "누적 판매 N만 돌파" 패턴을 `log10(N)` 점수로 환산. "BEST"/"베스트"는 0.5점.

가중치는 모듈 상단 상수 `VALIDATION_WEIGHT_*`로 노출.

**시각화: 회귀선 + 잔차 부호 색분리**

- x축: `rank`(1→100)
- y축: Validation Score
- 단순 OLS 회귀선 한 줄 — "이 순위에 보통 있는 검증 점수"의 기대값
- 잔차(점 - 추세선) 부호에 따라 점 색 분리:
  - 잔차 ≥ 0 → 녹색(검증된 강자) — 활동량이 순위 대비 풍부
  - 잔차 < 0 → 오렌지(푸시/신상 의심) — 활동량이 순위 대비 빈약
- 절댓값 상위 3 양수, 3 음수에만 라벨링
- 분면 배경/라벨/분할선은 모두 제거. 4분면 개념을 버린다.

**4분면을 버리고 회귀선으로 간 이유 (2026-05-14 결정):**

(a) 양수만 갖는 두 변수를 중위값으로 4등분하는 건 통계적으로 임의 분할에 가까움. 사분면 개념은 원래 데카르트 좌표에서 (음/양)×(음/양)으로 자연 분할될 때 의미가 강함.
(b) 무신사 평점이 90~98에 압도적으로 몰려 변별력이 0에 가까웠음. 플랫폼 모더레이션·푸시·적립금 등으로 점수가 천장에 박힌 결과.
(c) 회귀선의 잔차는 "선까지의 거리"라는 **자연스러운 metric**이라 분면 개수에 얽매이지 않고, 숫자 그 자체로 outlier를 정렬 가능.
(d) 분류가 필요한 경우(outlier 카드)는 잔차 임계치(±0.3)로 표현. Y축 변수 분포에 따라 표시 개수가 자연 조정됨.

### 3. HHI 브랜드 집중도

```
HHI = Σ (brand_share_pct ** 2)   # 0 ~ 10000
```

표시 임계점 (미국 반독점 기준 차용):

- HHI < 1500: **분산** (경쟁적)
- 1500 ≤ HHI < 2500: **보통**
- HHI ≥ 2500: **집중**

### 4. Outlier 5종 (v2.1 갱신)

검증 신호(누적 리뷰, 실구매, 판매 라벨)와 회귀 잔차에 기반해 재정의했다. 평점은 사용하지 않는다.

| 카테고리 | 조건 |
| --- | --- |
| 지금 가장 뜨거운 | `heat = viewers_now + buyers_now * 2` 내림차순 TOP 5 (rank 무관) |
| 누적 판매 강자 | `sales_label_score >= 1.0` (판매 1만+ 라벨) AND `rank > 50` |
| 검증된 숨은 강자 | 회귀 잔차 `residual > +0.3` AND `rank > 30` |
| 푸시/신상 의심 | 회귀 잔차 `residual < -0.3` AND `rank <= 30` |
| 할인 의존 | `discount_rate >= 40` AND `rank <= 30` |

각 리스트 최대 5건. 조건 미충족 시 카드는 "해당 없음"으로 표시.

### 5. 가격 jitter dot strip

가격 100개를 로그 스케일 x좌표 + 시드 기반 y jitter로 흩뿌려, 분포·outlier·클러스터를 한 줄(높이 60px)에 본다. 막대 히스토그램의 구간 경계 자의성을 피한다.

### 6. 가격 × 순위 6×10 히트맵

가격 6구간 (`~3만`, `3~5만`, `5~10만`, `10~20만`, `20~50만`, `50만~`) × 순위 10구간(1-10, 11-20, …, 91-100). 셀의 alpha = `count / max_count`.

### 7. 한 줄 데이터 품질

"수집 100/100 · 누락 0건" 형태의 한 줄 문장. v1의 디버그성 표(섹션 ID, 카테고리 코드 노출)는 제거.

## UI 원칙

- **내부 식별자 전면 제거**: `sectionId=199`, `001000`, `client-api`, `199` 태그가 화면에 보이면 안 된다.
- **카테고리명을 1급 시민으로**: 헤더의 진한 블루 그라데이션을 버리고 흰 배경 + 48px+ 디스플레이 타입의 "상의".
- **시간**: KST를 1차 표기(`2026-05-14 11:13 KST`), UTC는 푸터 보조.
- **색**: accent 보라 1색 + 빨/오렌지(경고) + 회색 스케일. 7색 카테고리 컬러 코딩 금지.
- **차트**: 외부 CDN 0. 인라인 SVG + CSS만.
- **표**: 모두 `<details>` 안에 접어 둠. 메인 뷰는 차트와 카드.
