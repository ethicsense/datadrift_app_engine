# Silhouette (concept UI)

도메인 킷을 고르면 분석에 필요한 모델이 연결되는 **Silhouette** 첫 화면 컨셉입니다.
내부 파이프라인·API·분석 엔진은 포함하지 않습니다. UI 아이디어만 미리 보여주는 정적 데모입니다.

## 실행

```bash
cd v3
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173` 을 엽니다.

## 무엇이 보이나요

- **도메인 킷** 선택 (예: 패션 리테일, 차량 번호판 식별)
- 선택한 킷이 필요로 하는 **모델 슬롯** 미리보기
- 활성화 시 컨셉 안내 메시지 (실제 워크스페이스 진입은 없음)

## 범위 밖

수집·드리프트·온톨로지·모델 다운로드 등 제품 워크스페이스와 백엔드는 이 폴더에 없습니다.
